Justified Exceptions (6 items not migrated)

EXCEPTION FestiveTemplateGrid card buttons

Reason: Template cards are card-shaped interactive selection targets. The Button component doesn't support card-style layouts with image, title, description, and metadata.

EXCEPTION EarnFormulaBanner complex content

Reason: The Banner component only accepts a text: string prop. This banner renders complex formula visualization with math operators, styled blocks, and dynamic calculations that cannot be expressed as plain text.

EXCEPTION CampaignBanner (storefront)

Reason: Storefront uses hardcoded hex colors by design (per CLAUDE.md). The Banner component's layout doesn't match the complex storefront banner with icon, multiplier badge, and date display.

EXCEPTION IssueGiftCardForm date input

Reason: The Input component does not support type="date". Native date input preserved for browser date picker functionality.

EXCEPTION ConversionsList HTML table

Reason: Already uses Pill for status badges. The HTML table has complex custom cell rendering (phone numbers, order IDs) that the Table component's API doesn't easily accommodate.

EXCEPTION Sidebar navigation item buttons

Reason: Navigation items (.nav-item, .nav-parent) have specialized interaction patterns (expand/collapse, active state, sub-items). Only the toggle button was migrated to Button.

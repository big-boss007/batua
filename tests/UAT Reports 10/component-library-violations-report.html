From CLAUDE.md — Component Library section:

## Component Library — MANDATORY CHECK BLOCKING: Before writing ANY UI element, call list_components from Svelte UI Components MCP. If the library has it (Button, Input, Select, Toggle, Pill, Progress, Table, Modal, Tabs, Pagination, Avatar, Tooltip, etc.), use it. Do not build custom versions.

The @juspay/svelte-ui-components library provides 55 components. This report identifies all places in the codebase where custom HTML/CSS was used instead of the available library component.

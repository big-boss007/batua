What Was Fixed

Issue #3 from the Visual Consistency Audit (docs/visual-audit/report.html): "Stat Card Styling Inconsistency". Four admin pages used stat/metric cards with two different implementations — Overview used the MetricCard component while Gift Cards, Referrals, and Influencers used custom inline .stat-card / .metric-card divs with different padding, font sizes, and structure.

Fix: Added size prop ("default" | "compact") and displayValue string prop to MetricCard.svelte. Migrated all three pages to use <MetricCard size="compact">. Removed all custom stat card CSS from those pages.

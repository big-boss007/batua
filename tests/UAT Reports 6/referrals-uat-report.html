#5 Conversion Rate Calculation BUG MEDIUM

  1. Compare the displayed conversion rate (0.6%) with the actual data
  2. Query DB: 67 conversions / 119 referrals = 56.3%
  3. The admin UI shows 0.6% which is incorrect

Metric card shows 0.6% conversion rate — should be 56.3%

Expected: Conversion rate should display as 56.3% (67/119 * 100)

Actual: Displays as 0.6% (the raw decimal 0.563 rounded to 1 decimal, shown with % suffix)

Root cause: src/services/referrals/storage.rs:328 computes total_conversions as f64 / total_referrals as f64 yielding 0.563, but does not multiply by 100. The frontend at +page.svelte:275 shows analytics.conversion_rate.toFixed(1)% treating the value as already a percentage.

Fix: Multiply by 100 in the backend: (total_conversions as f64 / total_referrals as f64) * 100.0

#9 Bucket Breakdown Shows All Zeros

BUG
  1. After loading customer dashboard, observe Bucket Breakdown section
  2. Compare bucket values against the spendable balance
Bug (MEDIUM): Bucket Breakdown section shows: Earned ₹0.00, COD Pending ₹0.00, On Hold ₹0.00, Expiring Soon ₹0.00. However, the Spendable Balance is ₹2,112.29 — the Earned bucket should reflect this amount.

Root cause: Bucket breakdown likely aggregates by bucket_type but the balance comes from a different calculation. The earned_credit entries exist in the ledger but aren't being summed into the breakdown correctly.

#10 Loyalty Tier Display Missing Tier Name

BUG
  1. Observe Loyalty Tier section in the customer dashboard
  2. Check if tier name (e.g., "Gold") is displayed
  3. Check if multiplier matches the customer's actual tier
Bug (MEDIUM): The Loyalty Tier section shows a star icon and "You've reached the highest tier" but does not display which tier the customer is in (e.g., "Gold" or "Platinum"). The customer (Rajesh Iyer / Vikram Singh in Chai & Co) is in the Gold tier per the database.

The multiplier banner says "Earning 1x rewards on every order" which is the base rate, not the Gold rate (1.5x).

Root cause: The tier name and multiplier are not being fetched or displayed from the customer_tiers table. The UI shows a generic "highest tier" message and the default 1x multiplier.

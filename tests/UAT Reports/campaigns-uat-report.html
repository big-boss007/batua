#11 No Create Custom Campaign Button

BUG
  1. Scan the entire campaigns page for a "Create Campaign" or "New Campaign" button
  2. Check page header, both sections, and any floating action buttons
Bug (MEDIUM): No visible "Create Campaign" or "New Campaign" button exists for custom campaigns. Only festive templates are available for creating campaigns. Merchants wanting to create a custom multiplier campaign (e.g., "Flash Sale", "Anniversary Sale") have no option to do so.

Root cause: Create campaign form/modal not implemented; only template-based creation is available.

#12 No Campaign Management Actions

BUG
  1. Inspect the active "Summer Sale 2x" campaign card for action buttons
  2. Look for edit, deactivate, or delete options
  3. Check for context menus or hover-revealed actions
Bug (MEDIUM): The active campaign card has no edit, deactivate, or delete buttons. Merchants cannot modify dates, multiplier, or toggle active/inactive from the UI. There is no way to end the "Summer Sale 2x" campaign early if needed.

Root cause: Campaign CRUD operations not fully implemented in the admin UI. The backend may support these operations, but the frontend does not expose them.

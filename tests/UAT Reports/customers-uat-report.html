#6 Phone Number Format

BUG
  1. Observe phone number formatting in the table
  2. Compare against standard Indian phone number formatting conventions
Bug (LOW): Phone numbers are displayed in raw format: +919000000004. Would be more readable as +91 90000 00004 or just 9000000004. This is a minor UX issue — the data is correct, just not formatted for readability.

#7 No Customer Detail Panel

BUG
  1. Click on a customer row in the table
  2. Observe that the cursor is pointer (indicates clickable)
  3. Verify whether a detail panel or view opens
Bug (MEDIUM): Clicking on a customer row shows cursor: pointer (clickable appearance) but no detail panel opens. Unlike the Transactions page which has a detail side panel, the customers page has no detail view. Expected behavior: click to see customer details including wallet balance, loyalty tier, and transaction history. Root cause: customer detail/profile view not yet implemented.

#8 No Wallet Balance Column

BUG
  1. Review the table columns: Name, Phone, Email, Joined
  2. Check for wallet/loyalty related columns
Bug (LOW): The customer table only shows Name, Phone, Email, and Joined columns. Missing useful columns: Wallet Balance, Loyalty Tier, Total Earned. These would help merchants quickly identify high-value customers. Root cause: table design does not include wallet/loyalty data.

#9 No Export/Download Option

BUG
  1. Look for an export or download button on the customers page
  2. Check toolbar/header area for CSV/Excel export options
Bug (LOW): No export button to download the customer list as CSV. This is a common admin feature for reporting purposes. Merchants would benefit from being able to export customer data for external analysis or CRM integrations.

#10 No Customer Count Displayed

BUG
  1. Look for a total customer count anywhere on the page
  2. Check pagination area for "Showing X of Y" style text
Bug (LOW): Total customer count is not shown anywhere on the page. Pagination shows page numbers but does not display "Showing 1–25 of 26 customers" or similar. This is a minor UX gap that would help merchants understand the size of their customer base at a glance.

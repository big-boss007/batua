#13 Storefront — Title Visibility BUG LOW

  1. Navigate to the gift card check page
  2. Observe the "Check Gift Card" heading text visibility

Title "Check Gift Card" is nearly invisible against dark background

Expected: The "Check Gift Card" heading should be clearly visible on the dark storefront card

Actual: The heading uses color: var(--color-text) which resolves to a dark color, making it barely visible against the dark card background (#1a1d27)

Root cause: The .gift-check-title CSS class uses var(--color-text) which is designed for light backgrounds. The storefront card uses hardcoded dark hex colors intentionally, but the title doesn't use a hardcoded light color to match. The subtitle works fine because it uses var(--color-text-muted) which has better contrast.

Suggested fix: Change .gift-check-title color to a hardcoded light value (e.g., #e5e7eb) or use var(--color-text-muted) which has better contrast on the dark card

Reproduction rate: Always

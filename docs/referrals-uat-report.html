  2. Verify the Program configuration tab is displayed as the default view
  3. Check that the referral reward value is shown correctly

Expected: Program overview tab displays the configured referral reward amount, program status, and program settings.

BUG-1 (MEDIUM): Referral reward value displays as "0" on the admin overview tab. The reward_amount field is not being loaded or displayed correctly in the overview component. This is likely the same class of issue seen previously (B1 in the v2 report) where $state() initializes from a prop at mount time before async data arrives, and never updates reactively when the prop changes from null to the loaded value.

Principle: The word "Program" is replaced with context-specific terms. The sidebar says "Tiers", so the page should talk about tiers, not a generic "program". The underlying data model (LoyaltyProgram, createProgram) stays unchanged — only user-facing labels are updated. Variable names in code remain as-is since they match the API types.

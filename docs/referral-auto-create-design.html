State 2A
Tradeoff Advice — "On Registration" Selected
Shown inline below the trigger setting when "On registration" is selected. Advises the merchant on what this means.
When should referral codes be created?
Maximises referral reach Every new customer gets a code immediately and can start referring friends right away. Some codes may go unused if customers don't engage further, but this is the best option for most stores.
State 2B
Tradeoff Advice — "On First Purchase" Selected
Shown inline below the trigger setting when "On first purchase" is selected.
When should referral codes be created?
Only active buyers get codes Codes are created after a customer's first order, ensuring only engaged buyers can refer. However, customers won't be able to share their code until they've made a purchase. Choose this if you want to avoid unused referral codes.
State 3
Edit Mode — Reconfigure Existing Program
When merchant clicks "Edit Program" on an active program. The trigger is pre-filled with the current value and can be changed.
Reconfigure mode: Your current settings are pre-filled. Changes take effect immediately on save.

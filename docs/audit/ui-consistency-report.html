P Priority Fixes

Ordered by impact on merchant experience.

  1. Standardize data lists — pick one pattern (Table component) for all tabular data; use card lists only for non-tabular content like campaign templates
    Affects: Rules, Tiers, Campaigns, Wallet Policies
  2. Standardize modals — one modal component with consistent header border, close button, width, and information layout
    Affects: Customer Detail, Transaction Detail, Rule Form, Campaign Form
  3. Standardize page headers — every page should have title + subtitle describing the page purpose
    Affects: Gift Cards, Referrals, Analytics, Notifications, Settings
  4. Standardize content width — global max-width: 1100px on all page content
    Affects: Transactions (full width), Customers (full width), Referrals (too narrow)
  5. Standardize form layout — forms always in cards, labels always semibold, buttons always right-aligned in footer
    Affects: Referrals (bare form), Settings My Store (left-aligned button)
  6. Standardize stat cards — one visual pattern for summary number cards across Dashboard, Gift Cards, and Analytics
    Affects: 3 pages with 3 different stat card styles
  7. Remove nested tabs in Memberships — replace with button toggle or inline form
    Affects: Memberships tab UX
  8. Fix phone formatting in Memberships table and remove duplicate Notifications tab from Settings
    Quick fixes — low effort, high polish

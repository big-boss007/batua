Stakeholder 1: Merchant Admin (/admin/referrals)

T1 – Program Tab: Navigation & Form Display BUG

Steps: Navigate to /admin/referrals for Desi Drapes. Program tab is the default tab.

Expected: Form pre-populated with DB values: referrer_reward=70, referee_reward=39, max_referrals=17, is_active=true, limit=true.

Actual: All three numeric fields show 0. Toggle states (active, limit) are correct (both checked).

API Response:

GET /referrals/programs/b0000000-...0002 → 200 — {"referrer_reward_amount":70.0, "referee_reward_amount":39.0, "max_referrals_per_customer":17, "is_active":true}

Root Cause (B1): ReferralProgramForm.svelte initializes $state() from program prop at mount time. Since API data loads async, program is null at mount, so defaults to 0. Prop changes are never reflected.

T3 – Program Tab: Update Program API Call BUG

Steps: Set referrer=75, referee=40, max=20. Click "Update Program".

Expected: Successful PUT/POST with updated values, toast confirmation.

Actual: POST /referrals/programs returns 422. No toast shown. Silent failure.

POST /referrals/programs → 422 — "missing field `merchant_id` at line 1 column 105"
Request body: {"referrer_reward_amount":75,"referee_reward_amount":40,"max_referrals_per_customer":20,"is_active":true}

Root Cause (B2, B5): remote.ts createProgram() omits merchant_id. Also, ReferralProgramForm.svelte handleSubmit() is not async-aware — isSubmitting resets immediately, and the error toast from the page handler may not fire because onSave is not awaited.

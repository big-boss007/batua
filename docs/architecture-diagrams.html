11. Ledger — The 8 Foundational Truths

How Each Truth is Enforced
TruthPrincipleImplementation
1Merchant-scoped walletUNIQUE(merchant_id, customer_id). Bearer instruments via nullable customer_id + bearer_code.
2Atomic tripleearning_unit + currency_equivalent + conversion_rate on every ledger entry. All three immutable.
3Four movements + heldmovement_type ENUM (in, held, out, across). Held excluded from spendable balance query. Across uses shared transfer_id.
4Traceable causeevent_id + rule_snapshot_id + campaign_snapshot_id + actor_type + actor_id on every entry. Snapshots are immutable.
5Books balanceDouble-entry at write layer. Negative net in a bucket is valid (reversals). Redemption validation is above the ledger.
6Value not fungiblebucket_type + constraints JSONB locked at earn time. Different origin = different rules for transferability, expiry, stackability.
7Time is first-classAppend-only. prevent_ledger_mutation trigger rejects UPDATE on core columns. Expiry is an out entry, not deletion. get_balance_at for historical reconstruction.
8Structural idempotencyidempotency_key TEXT UNIQUE on ledger_entries and events. SHA256(merchant+event+rule). Duplicate = silently rejected.

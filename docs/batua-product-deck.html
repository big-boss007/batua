04 Interfaces

Three Interfaces

Each audience gets a purpose-built UI.

🏪
/admin/*
Merchant Admin — the primary interface. Merchants manage their wallet program, loyalty tiers, gift cards, referrals, campaigns, and settings.

🛡️

👤

Customer Storefront — end-customer facing. Customers enter their phone number to view balance, tier, transactions, referral code, and membership status.
Phone login, Balance card, Tier badge, Transaction history, Referral sharing, Membership status

06 Wallet

Wallet & Policies

Configure the points currency and per-bucket redemption/earn rules.

Points Configuration
Points Name — e.g. "Stars", "Coins", "Gems"
Icon — e.g. ★, 🪙, 💎, pts
Value per Point (₹) — conversion rate (e.g. 0.25 = 4 pts = ₹1)

Live preview panel shows the computed ratio. Saved per merchant.
Active Earn Rates
Auto-populated from active reward rules. Shows examples like:
"On a ₹1,000 order → customer earns 100 ★ worth ₹25 · expires in 90 days"
Global Bucket Policies
One policy per bucket type per merchant. Each controls:

Redemption side:
- Min redemption amount
- Step size (redeem in multiples of X)
- Max per order (% or fixed ₹)
- Stackable with discounts toggle

Earn side:
- Default conversion rate
- Default expiry days

Movement:
- Is transferable
- Excluded payment methods (e.g. COD)
- Excluded collections
07 Loyalty

Earn Rules

Configure how customers earn and burn points. Rule engine with event-based triggers.

Rule List View
Each rule shows: name, type badge (reward), event type, version, active/inactive status, and performance stats (entries, total value, unique customers).

Actions: Create new, Edit (opens modal), Activate/Deactivate toggle.
Rule Form (Modal)
Fields: Name, Rule Type, Event Type (order_placed, etc.)

Action config:
- Calculation: percentage or fixed
- Value (% or fixed amount)
- Max amount cap
- Expiry days
- Target bucket type
How Earn Works (Backend Flow)
Shopify Event
→
Event Service
→
Rule Engine
→
Earn Service
→
Ledger Entry

Rule matching: Active rules for the merchant are evaluated against the event. The rule config determines the earn amount, bucket, and expiry.

Performance tracking: Each rule tracks total_entries, total_value, unique_customers — displayed on the rules list.

Versioning: Rules are versioned. Each update increments the version and creates a rule_snapshot for audit.
08 Loyalty

Loyalty Tiers

Tiered loyalty programs with automated customer evaluation and distribution tracking.

Tier Wizard
Guided setup for new loyalty programs. Two modes:

Fresh: Creates program + initial tiers
Reconfigure: Modifies existing program

Configures: Program name, Evaluation criteria (spend / order_count / points), Evaluation period (lifetime or last N days)
Tier Management
Each tier has: Name, Rank (ordering), Threshold (qualification point), Earn Rate Multiplier (e.g. 2x for Gold), Benefits (JSON).

Actions: Add Tier, Edit inline, Delete with confirmation. Visual TierBadge component shows rank-based styling.
Program Summary
3-column grid showing: Program Name, Evaluation Criteria (Total Spend / Order Count / Points Earned), Evaluation Period (Lifetime / Last N days).
Evaluate Tiers
One-click action that re-evaluates all customers against tier thresholds. Shows result: "Evaluated 842 customers".

Updates the Tier Distribution Chart — visual breakdown of how many customers fall into each tier.

Customer Tier Table

Database: customer_tiers — tracks merchant_id, customer_id, tier_id, evaluated_value, assigned_at. Updated on evaluation or manual override.

09 Loyalty

Memberships

Paid or assigned tier access with expiry. Supplements organic loyalty tiers.

Subscribers Tab
Table of all membership holders. Filterable by:
- Tier name (Bronze, Silver, Gold, Platinum)
- Status (Active, Expiring Soon, Cancelled, Expired)
- Search (name, phone)
- Pagination

Each row shows: Customer name/phone, Tier badge with color, Multiplier, Expiry date, Status pill, Days remaining.

Click a row → Detail modal with full membership status and actions.
Membership Actions (Detail Modal)
Upgrade: Move customer to a higher tier immediately
Extend: Add N days to expiry (default 365)
Renew: Reset expiry to 1 year from now
Cancel: Deactivate with confirmation

Each action calls a dedicated API endpoint and refreshes the subscriber list.
Assign Membership Tab
Lookup customer by phone → shows current tier, wallet balance, existing membership if any.

Select target tier, set duration → assigns membership. Shows confirmation with previous vs new tier.

Membership overrides organic tier if its multiplier is higher.
10 Loyalty

Campaigns

Time-bound multiplier campaigns with festive templates and stacking configuration.

Campaign Creation
Two creation paths:

1. Festive Templates: Pre-built campaigns for Indian festivals (Diwali, Holi, Eid, etc.) with pre-configured multipliers and date ranges. Select template → customize → launch.

2. Custom Campaign: Full control over name, multiplier, start/end dates, target rules. Created via CampaignForm modal.
Active Campaign Banner
When a campaign is live, an EarnFormulaBanner shows at the top — displays the current earn formula with the campaign multiplier applied.

Example: "Base rule: 10% → Campaign 2x → Effective: 20% earn rate"
Campaign List
Table showing all campaigns: Name, Status (active/upcoming/ended), Multiplier, Date range. Click for detail modal.

Actions: View detail (CampaignDetailModal), Deactivate running campaigns.
Stacking Configuration
Global settings modal (StackingConfigModal):

Stacking Mode: multiplicative (multipliers compound) or additive
Max Campaign Multiplier: safety cap (e.g. 10x)

Prevents runaway point issuance when multiple campaigns overlap.

12 Operations

Customers

Browse, search, and drill into customer details with full wallet visibility.

Customer List
Paginated table showing: Name, Phone, Email, Join Date.

Search: Debounced search by name or phone across all merchant customers.
Pagination: 25 per page with server-side filtering.

Click any row to open the customer detail panel.
Customer Detail Panel
Comprehensive customer view powered by CustomerDetail component:

- Profile: Name, phone, email, birthday
- Wallet Balance: Spendable balance, bucket-wise breakdown
- Current Tier: Loyalty tier with multiplier
- Membership: Active membership status, expiry
- Order Stats: Total orders, lifetime spend, average order value
- Recent Transactions: Last N ledger entries
- Referral Code: If customer has one

14 Referrals

Referrals & Influencers

Two-sided referral rewards with influencer/creator mode and fraud detection.

Referral Program Setup
Three-step wizard: Set Rewards → Configure → Share.

Config:
- Referrer reward amount (points)
- Referee reward amount (points)
- Max referrals per customer (optional cap)
- Active/Paused toggle

One program per merchant. Edit Program button for reconfiguration.
Dashboard View
Status banner: Active/Paused — Referrer: X pts · Referee: Y pts

Stats grid: Total Codes, Total Referrals, Conversions, Conversion Rate

Referral Codes table: Code, Customer ID, Vanity flag, Creator flag, Total Referrals, Conversions, Status

Recent Conversions table: Referrer → Referee, Order ID, Suspicious flag, Fraud signals, Date
Influencers Page
Filtered view of creator-flagged referral codes only.

Stats: Total Influencers count, Total Conversions from creators.

Add Influencer Modal:
- Enter mobile number (resolves customer via identity service)
- Set vanity code (e.g. "PRIYA10")
- Set commission rate (%)

Each influencer card shows: code, total referrals, conversions, commission rate, active status.
Anti-Fraud Signals
Each conversion tracks:
- referee_ip — IP address
- referee_device_fingerprint
- is_suspicious flag
- fraud_signals JSON array (e.g. ["same_ip", "rapid_signup"])

Suspicious conversions are highlighted in the admin UI.
15 Notifications

Notifications

Template-based notification management with delivery logs.

Templates Tab
List of notification templates per merchant. Each template has:
- Channel (SMS, Email, WhatsApp, Push)
- Event trigger (order_placed, points_earned, etc.)
- Subject & body with template variables
- Active/Inactive toggle

Click to edit via NotificationTemplateEditor — inline editing with save/cancel.
Logs Tab
Table of sent notifications:
- Channel
- Status (sent, failed, pending)
- Timestamp

Paginated, 50 per page. Useful for debugging delivery issues.

My Store Tab

- Store name

- Storefront slug

17 Storefront

Customer Storefront

Customer-facing rewards page at /s/{slug}. Phone-based login, no passwords.

Phone Entry
Customer enters phone number → normalized to E.164 → stored in local storage for return visits.

Looks up customer via identity service → loads wallet, balance, tier, referral code, membership status in parallel.
Balance Card
Shows spendable balance in merchant's points currency + ₹ equivalent.

"Lifetime Saved" calculation: sum of all In/Released entries' currency equivalents.
Tier Card
Shows effective tier — the higher of organic loyalty tier and membership tier. If membership has higher multiplier, it takes precedence.

Displays: tier name, earn rate multiplier, and membership expiry days if applicable.
Transaction List
Last 10 transactions with running balance computation. Each entry shows: description, bucket type, movement, amount, date, running total.
Referral Card
If merchant has an active referral program and customer has a code: shows the code with share functionality.

Displays: referrer reward, referee reward amounts. Shareable link for social/WhatsApp.
Profile Bar
Customer name at top + "Change Phone" to switch accounts.

Design note: Storefront uses hardcoded hex colors (#1a1d27, #2a2d3a, #4ade80) — intentional for the card-style dark theme, not CSS variables.

VIP Tiers — Where to place the cap-mode setting

Three placements within the existing VIP Tiers page. Same setting, three locations and visual weights. Sherwani Studio's actual 5-tier ladder is used as the live data.

1 Header strip · minimal  ·  2 Inline section above the table · contextual  ·  3 Impact panel below the table · consequence-first

Key design changes:
1. No more tabs — single-page dashboard. Program settings, codes, and conversions are all visible in one flow.
2. Empty state with wizard steps — guides the merchant instead of showing a bare form.
3. Status bar — always visible at top showing program state + key config at a glance.
4. Metrics row — analytics inline on the dashboard, not hidden in a separate tab.
5. Add Creator Code (not "Create Code") — only for influencer/creator partnerships. Regular customers get auto-generated codes from the storefront.
6. Mobile number as identifier — all tables show mobile numbers instead of internal customer IDs. More human-readable for merchants.
7. Edit program as dedicated view — "Edit Program" button opens the config form with pre-filled values + change indicators.
8. Recent conversions inline — no separate tab, visible below codes table.

Bucket Classification

POINTS earned_credit, cod_pending, referral_reward, goodwill_credit, membership_benefit

MONEY gift_card, customer_funded, refund_credit

Points buckets show earning_unit + "★"
Money buckets show currency_equivalent + "₹"

Merchant Config (new fields)

points_name = "Stars" (default: "Points")
points_icon = "★" (default: "pts")
points_to_currency_rate = 0.25 (1 Star = ₹0.25)

This means: 4 Stars = ₹1
Balance: 1,400 ★ = ₹350

Display Rules

Balance card: Shows points as primary number, ₹ equivalent below

Cash balance: Separate card below — gift cards + refunds + customer-funded, always in ₹

Total redeemable: (points × rate) + cash = ₹ total. This is what gets applied at checkout

Transactions: Each row shows in its native unit. Points transactions show ★, gift card transactions show ₹

Backend Changes

1. Add points_name, points_icon, points_to_currency_rate to merchants table

2. Balance endpoint adds points_balance and cash_balance split

3. build_wallet_balance returns both earning_unit and currency_equivalent sums per bucket

4. Storefront API includes merchant point config in response

Edge Cases

Conversion rate = 1.0: 1 point = ₹1 → "500 Stars (worth ₹500)". Still shows both but they happen to match.

Gift card redemption: Always in ₹. No points conversion needed.

Mixed redemption at checkout: "Using 400 ★ (₹100) + ₹200 Gift Card = ₹300 off"

Referral rewards: Stored as points in earning_unit. Shown as "400 ★" not "₹100"

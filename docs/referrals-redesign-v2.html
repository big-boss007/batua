Key design decisions:
1. Two sub-pages under Referrals — "Referral Program" owns program config + all codes + conversions. "Influencers" owns creator partnerships.
2. Referral Program page has no "Create Code" button — standard codes are auto-generated from the storefront by customers.
3. Influencers page has its own metrics (active count, conversions, commissions earned) and a dedicated table with name, code, commission %, earnings.
4. Mobile number everywhere — no internal customer IDs shown to merchants.
5. Creator codes on Referral Program page show as Creator type in the all-codes table, linking the two views.

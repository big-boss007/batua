What the wizard does not do (today)

  • No way to re-enter the wizard after onboarding completes — the gate (S2) is terminal.
  • No connector setup step (Shopify webhook, WhatsApp BSP, logistics provider for COD).
  • No notification templates step — merchant lands with default copy, has to discover Settings → Notifications.
  • No storefront branding step — slug, colors, customer-facing copy.
  • No memberships step — paid tiers are admin-only post-onboarding.
  • No milestones / streaks / birthday bonus / spin wheel — all the engagement rewards that exist in code are invisible during onboarding.
  • Tier thresholds and multipliers are hard-coded in the Tiers step.
  • The Done step's "View Storefront" button uses merchant.slug or falls back to merchant.external_id — fine but ad hoc.

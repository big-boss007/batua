SF-03: Initial State — BUG-1 Discovery (Before Fix) BUG
  1. Same as SF-02 but before the isPointsBucket fix

Expected: Points shown as ★

Actual: ALL transactions showed as "cash" with ₹ amounts. Balance showed "0 pts" despite having ₹2,871.92. Every entry was treated as a cash bucket.

BUG-1 (HIGH): isPointsBucket() checked snake_case strings (earned_credit) but the Rust backend serializes BucketType::EarnedCredit as PascalCase in JSON. Every bucket was classified as "cash".

Fix: Added PascalCase variants to the Set. Applied during UAT.
Fix applied: Added EarnedCredit, CodPending, ReferralReward, GoodwillCredit, MembershipBenefit to POINTS_BUCKETS Set in foundation/utils.ts.

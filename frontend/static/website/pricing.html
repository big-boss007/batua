Common questions

Is it really flat pricing?

Yes. ₹2,999/mo is ₹2,999/mo whether you process 100 orders or 10,000. No per-order fees, no overage charges.

Do I need a developer to set it up?

No. Install on Shopify, run the setup wizard — cashback rule, wallet policy, tiers, referrals — and you're live in 5 minutes.

What about COD orders?

Breeze holds COD credits until delivery is confirmed via Shiprocket/Delhivery webhook. Auto-cancelled on RTO. You don't touch anything.

Can I try before paying?

The Free plan includes wallet with 100 transactions per month. No credit card required. Upgrade whenever you're ready.

Which WhatsApp providers do you support?

Interakt, WATI, and AiSensy. Template-based with variable injection. Swap vendors without changing anything in Breeze.
